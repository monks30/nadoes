If the fetch fails

Sleeper's read API is public, so the usual cause is your browser blocking a request made from a double-clicked file (a file:// address). Two fixes:

Easiest: run it from a local server so the address becomes http://localhost. Put this file in a folder, open a terminal there, and run
python -m http.server 8000
then open http://localhost:8000/ (the trailing slash serves whichever HTML file is in the folder, so the name does not matter). This local-server step is only a laptop fallback; on GitHub Pages you skip it entirely.

Check the league is public: open https://api.sleeper.app/v1/league/1391256159565930496 in a browser tab. If you see JSON, the API is reachable and the issue is the origin rule above.

The exact error appears in the status line on the Projections tab and in the browser console (F12). Paste it back to me if it sticks.
